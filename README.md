# ProgressionLESS: Gravship

Keeps the grav engine from falling until your colony reaches the Spacer era, and holds back the gravship quest line until then. Includes compatibility for Progression: Scenarios, Debt-Bound Gravship, Orbital Station Start and Vanilla Gravship Expanded.

Forked from [Progression: Gravship](https://steamcommunity.com/sharedfiles/filedetails/?id=3522893553) by ferny.
